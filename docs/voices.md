# Jet Lancer — 등장인물 말투 가이드

## 1. 기본 규칙

- **일본어(원문 컬럼 9) 1차 참고**, 영문(컬럼 4)은 보조.
- 일본어 원문 속 **라틴 문자 고유명사**는 그대로: `Ash`, `Steve`, `Lem`, `Gin`, `AEGIS`, `Black Knight`, `LANCER_01`, `FINAL RETORT`, `Pierce`, `Lex`, `Hex`, `NEW GAME+`, `TO LOADOUT`, `GAMEPAD`, `LMB`, `OP 21:`, `HMS Vanguard` 등.
- 마크업/이스케이프 보존: `#`, `^`, `[c=..]`, `[t=..]`, `{}`, `<>`, `\n`, `[g]…[/g]`.
- 허용 문자: 한글 / ASCII / `. , ! ? ' " - : ; ( ) ~ … — ·` 외 금지. 줄임표는 JP가 `…`/`...`일 때만 `...`.
- 금지: `~하는 것이다`, `~에 의해`, `그녀는/그는`(불필요한 대명사), `당신` 과잉.

## 3. 인물별 말투 (화자 → 청자)

### Pilot (Ash)
주인공 소녀 파일럿. 1인칭 `私`→`나`. 일본어 원문 전체가 반말(`です/ます` 0줄)이므로 함장에게도 반말: `~야`, `~어`, `~잖아`, `~지`, `~는 거야`. 당찬 말투. 함장 호칭은 `함장`(님 없음). 해요체/합쇼체 금지.
  - そうこなくちゃね→ 그래, 그걸로 됐어. 코스 설정했으니 사냥하러 출발하자.
  - ったく、Pierceのヤツ！→ 아, 진짜, Pierce 그 자식!
  - お荷物だったアンタを救った恩をこういう形で返すってわけね。やろうじゃない。→ 짐덩어리였던 너 구해준 은혜를 이렇게 갚는 거야? 한번 해보자.
  - 誰が言ってるの？→ 누가 그런대?
  - とっておきを使うまで、アンタに負けを認めるわけにはいかないんだ…→ 비장의 수 쓰기 전까진 네한테 진 걸 인정할 순 없어…

### Captain
거친 중년 함장, Ash의 상관. 1인칭 `俺`→`나`. Ash→`너`. 반말/하게체. 무뚝뚝·명령조. `~다`, `~ぞ`(`~다`), `~な(かん)`, `~ろう`, `~さ`
  - 戻ってこい、Ash。→ 돌아와, Ash. / お前は気に入らんだろうが…→ 너는 맘에 안 들겠지만…
  - よくやった、Ash！→ 잘했다, Ash! / 黙ってろ。→ 닥쳐.
  - 気をつけろよ、Ash。→ 조심해라, Ash.

  - なんてことだ。空賊は憎むべき相手だが、やつらにそんなことができたとは。→ 세상에. 하늘 해적은 증오해야 할 상대지만, 그 자식들에게 그런 능력이 있었다니.
  - 君はいい腕を持つパイロットだよ、Ash。→ 넌 실력 좋은 파일럿이야, Ash.
  - 僕の髪型を持ち出すな！→ 내 머리 스타일은 꺼내지 마!
  - 君は子供だな、Ashlyn。→ 넌 애야, Ashlyn.
  - ありがとう。功績を認めてもらえるのは…いいものだな。→ 고마워. 공적을 인정받는 건… 기분 좋은 거군.

## 4. 번역 경계

- `~하는 것이다` 지양 → `~는 거야`, 능동문 풀기.
- `~에 의해` 금지 → `~로`, `~덕에`, 능동으로.
- `그녀는/그는` 불필요한 주어 삽입 금지. 일본어 주어 생략 존중.
- `당신` = `あなた` 대응, 과용 금지. 기본 생략 or 호칭.
- 영문 `you`를 모든 문장에 기계적으로 살리지 않음.
- `~에 있어서`, `~에 대해서` 구태 번역체 금지.
